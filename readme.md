# [scale_calculator]

> A dedicated calculation tool built to transform architectural or engineering plan measurements between different scales (from 1:x to 1:y). Users provide the baseline measurement and both scale factors to obtain the accurate converted value. Additionally, it features a built-in unit converter to streamline calculations. 

> This is a project that i made for my partner who is studying architecture, and needed a way to convert measurements quick, so i also made it pretty for her 

> Inside the code, on line 256, if you change <const PERFIL_ACTIVO = "personal";> to <const PERFIL_ACTIVO = "generico";> it gives you a more standard version of the project
